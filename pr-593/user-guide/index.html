User Guide¶

This guide walks through RustGIS by task. Each page covers one part of the app:

Page What it covers
Data Vector and raster formats, adding data, large files, raster display, project items
Web Data Public web services and catalogs: STAC, Overture Maps, OpenStreetMap, NASA, open-data portals, satellite embeddings
Supported Data Formats Every format RustGIS reads and writes, how to add it, and its limits
Maps and Basemaps Basemaps and web tile layers, projections, the 3D globe, view effects and navigation
Cartography Symbology, labeling, layer effects and graphics
Editing Creating and modifying features, data design, the clipboard and pop-ups
Analysis Selection and SQL queries, geoprocessing, the GeoLibre tools, guided workflows, imagery
Layouts and Reports Page layouts, map series, reports, presentations and notebooks
Sharing Exports, packages and open-format web maps, layers, styles and scenes
Workspace Linked views, the Browser view, animation, profiles, offline areas, customizing the ribbon
AI Assistant A chat pane that answers questions and acts on the map through commands

The window¶

  • Ribbon: tabs of commands grouped by task. The Project button opens the backstage (new, open, save, About).
  • Quick Access Toolbar (top left): New, Open, Save, Undo and Redo, plus any commands you add under Settings › Customize › Quick Access.
  • Layers pane (left): the map's layers in drawing order, with their legends. Tick a layer to show or hide it; drag it up or down to change the drawing order; right-click it to zoom to it, rename or remove it and more. Type in the box at the top to show only the layers and tables whose names contain the text (Esc clears it); a selected layer it hides is no longer selected, and layers can be reordered again once it is cleared. The buttons beside the list's title list the layers by drawing order, by data source (grouped under the file, web address or database each comes from) or by selection (selectable layers first, each with a box to make it selectable or not and its count of selected features); only the drawing order reorders layers. A layer that isn't selectable is skipped by the Select tool's clicks and boxes on the map; Select By Attributes, Select Layer By Location and the attribute table still select in it, since they name the layer. Group layers to keep related ones together, such as one dataset drawn as several layers with their own visibility ranges: right-click a layer and pick Group › New Group, or move it into a group that already exists. A group folds open and closed with its arrow; its box shows or hides all its layers at once (each keeps its own box), and its menu renames it, sets a transparency over its layers' own, ungroups it (its layers stay) or removes it with its layers. Drag a layer onto a group's row, or between its layers, to put it in the group; drag it out of the group's rows to take it out. Drag the group's row to move all its layers in the drawing order. Scripts and the AI Assistant build groups with group.add, group.set, group.scaleRange (a visibility range on top of each layer's own), group.move, group.expand, group.ungroup, group.remove and layer.group. Copy Layer (or Copy Group, with its layers) from its menu and Paste Layer (or Paste Group) it on a layer (above it), a group or the map's name above the list (at the top, also when the map has no layers yet), after switching to another map if you like, or on a map in the Browser (at the top). The copy keeps its source, symbology, labels, transparency, scale range, definition query, display filters and mask, but not its selection, and a name the map already has gets " copy". Pasting into the same map duplicates the layer. A mask whose layer the map lacks is cleared, and said. Groups don't nest: pasted into a group (on it, or on one of its layers), a copied group's layers join it at the top. Scripts use layer.copy and layer.paste. The Style and Data tabs act on the layer selected here. The tabs at the top of the left pane switch it between Layers, Browser and Data Sources (also in View › Windows).
  • Map view: one tab per map and layout. The buttons at the top right zoom in, zoom out and go to the full extent; the north arrow and scale bar sit in the corners (on a rotated or tilted map, click the north arrow to face north and look straight down); tile credits at the bottom right.
  • Panes (right): Tools (geoprocessing), Symbology, History, Details, Editing, Workflows, Script, the AI Assistant and more. Open them from View › Windows or the commands that use them. Each pane opened gets a tab at the top, in the order opened: click a tab to show its pane, and its ✕ to close it (the next tab shows; closing the last hides the side). Right-click a tab to close it, the others or all; the ✕ at the header's end closes every pane. Tabs that don't fit are listed under ». A ribbon button for a pane shows it when it is open but not in view, and closes it when it is. Pane Sets keep the tabs open.
  • Status bar: the scale (type one, or pick from the list), the zoom level, bearing and pitch (click them to face north and look straight down again), the coordinate system (click it to change the projection), the pointer's coordinates (click them to switch between decimal degrees and DMS), the selection count and the draw time.

Command Search (Ctrl+K, or the box at the top right) finds any command or geoprocessing tool by name and runs it.

To give the map more room, collapse the ribbon to its tab row with the chevron at its right end, by double-clicking a tab, or with Ctrl+F1 (Cmd+F1 on macOS, where F1 may need the Fn key). Click a tab to peek at its commands while collapsed. When the window is narrower than the ribbon, arrows at its ends scroll it.

The tabs stay the same whatever is selected: Style and Data act on the layer selected in Layers.

Projects¶

A project (.rgis) holds maps, layouts, reports, presentations, notebooks, styles, tasks and models. Vector data added from files is stored inside the project, so a project file is self-contained; rasters are referenced by path on the desktop and stored inside the project in the web app. Project › New starts a blank map or the World Atlas sample; Save and Save As write the project, named after its file; a project opened from a file is named after that file too. See Project items for the other files RustGIS reads and writes.

Every change is a command, and every command can be undone (Ctrl+Z) and redone (Ctrl+Y).

Keyboard shortcuts¶

Keys Action
Ctrl+K Command search
Ctrl+N / Ctrl+O / Ctrl+S New / Open / Save project
Ctrl+Shift+S Save project as
Ctrl+Z Undo
Ctrl+Y / Ctrl+Shift+Z Redo
Ctrl+T Attribute table
Ctrl+F1 Collapse or expand the ribbon
Ctrl+= / Ctrl+- Zoom in / out
Home Full extent
Esc Back to Explore; cancel a sketch
Del Delete selected features
Ctrl+D Duplicate the selected layout element
Ctrl+C / Ctrl+X / Ctrl+V Copy / Cut / Paste features

On macOS, Cmd takes the place of Ctrl. Help › Shortcuts lists them all in the app, from the same table the app runs them from.
